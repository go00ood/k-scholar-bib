## 업데이트 기록 
### **1.2.0**

  * **추가된 기능**

    * 확장 프로그램 아이콘을 누르면 현재 논문의 서지정보와 변환될 파일명을 미리 확인할 수 있는 설정 화면 추가
    * 일반 논문과 학위논문의 파일명 형식을 각각 따로 설정하는 기능 추가
    * ‘한국어학’, ‘APA’, ‘사용자 지정’ 인용 양식 지원
    * 논문 제목과 학술지명에 낫표(「 」·『 』) 또는 화살괄호(〈 〉·《 》)를 적용하는 기능 추가
    * 권·호를 `37(3)`, `제37권 제3호`, `Vol.37 No.3` 등의 형식으로 설정하는 기능 추가
    * 쪽수 구분 기호를 하이픈(-), 엔 대시(–), 물결표(~) 중에서 선택하고 ‘쪽’과 같은 단위를 붙이는 기능 추가
    * `{저자}`, `{연도}`, `{논문제목}`, `{학술지명}`, `{권}`, `{호}`, `{학회명}`, `{페이지}` 등의 변수를 이용한 사용자 지정 파일명 기능 추가
    * 설정한 양식의 적용 결과를 저장 전에 확인하는 미리보기 기능 추가
    * 현재 논문의 서지정보와 조합된 인용 표기를 클립보드에 복사하는 기능 추가
    * RISS 학위논문의 제목·저자·연도·대학교·학위 구분을 인식하여 학위논문 형식으로 저장하는 기능 추가
    * 새 KCI 포털(KOAJ)의 논문 서지정보 인식 지원

  * **수정된 내용**

    * 여러 명의 저자가 등록된 논문에서 저자명이 올바르게 표시되도록 개선

      * 저자 1명: `홍길동`
      * 저자 2명: `홍길동·김민국`
      * 저자 3명 이상: `홍길동 외`
    * 각 사이트에서 논문의 시작 쪽수와 끝 쪽수를 분리하여 인식하도록 개선
    * 사용자 지정 양식에서 값이 없는 항목 때문에 빈 괄호나 중복 쉼표가 남는 문제 수정
    * RISS 등에서 원문이나 PDF가 새로운 탭으로 열릴 때 기존 탭의 서지정보가 전달되지 않아 파일명이 바뀌지 않던 문제 수정
    * 여러 단계에 걸쳐 새 탭이 열리는 경우에도 논문의 서지정보가 이어지도록 개선
    * 저장된 인용 양식이 실제 다운로드 파일명에 자동으로 반영되도록 파일명 생성 방식 개선
    * 기존 버전에서 저장한 설정을 1.2.0의 새 설정 구조로 자동 변환하도록 개선

한국 학술 논문을 다운로드할 때 저자, 연도, 제목 등 서지정보를 바탕으로 파일명을 자동 정리합니다.

학술 DB에서 논문을 다운로드할 때마다 파일명을 일일이 정리하고 계신가요?

숫자나 기호로 되어 있는 복잡한 파일명 대신,
논문의 서지정보를 바탕으로 알아보기 쉬운 파일명으로 자동 변경해 보세요.

논문 파일명 자동 변경기는 학술 논문을 다운로드할 때 저자, 연도, 논문 제목, 학술지명 등의 서지정보를 가져와 원하는 형식의 파일명으로 자동 변경해 주는 크롬 확장 프로그램입니다.
_________________________________________

✨ 주요 기능

🌟 논문을 다운로드하면 파일명이 자동으로 변경됩니다.
학술 DB에서 논문을 다운로드하면 논문의 서지정보를 바탕으로 파일명을 자동으로 만들어 줍니다.
논문을 열어보지 않아도 파일명만으로 어떤 논문인지 쉽게 확인할 수 있습니다.

🌟 학술지 논문과 학위 논문의 형식을 따로 설정할 수 있습니다.
1. 저장 방식 설정 가능 
한국어학, APA 형식뿐만 아니라
‘사용자 지정’을 선택하여 원하는 형식을 직접 입력할 수 있습니다.

2. 학위논문/학술지논문 별도 관리
학술지 논문과 학위 논문은 서지정보의 구성이 다르기 때문에 각각 원하는 파일명 형식을 설정할 수 있습니다.

_________________________________________

✨ 양식 적용 방법
한번의 설정으로 저장 양식을 설정할 수 있습니다. 

1. 크롬에서 확장 프로그램을 설치합니다.
2. 확장 프로그램 아이콘을 클릭합니다.
3. 학술지 논문 또는 학위 논문을 선택합니다.
4. 원하는 인용 형식이나 사용자 지정 양식을 설정합니다.

✨ 사용자 지정 양식 설정
 1️⃣  확장 프로그램에서
‘인용양식 → 사용자 지정(직접입력)’을 선택합니다.

 2️⃣  원하는 위치에 변수나 기호를 넣어 원하는 형식을 만듭니다.

💡 사용할 수 있는 변수는 다음과 같습니다.
  {저자}, {연도}, {논문제목}, {학술지명}, {권}, {호}, {학회명}, {페이지}

💡적용 예시
☑️ {저자}({연도}), 「{논문제목}」, 『{학술지명}』 {권}({호}), {학회명}, {페이지}.
→ 김민국(2017), 「‘에서’ 주어의 통사와 의미」, 『국어학』 81, 국어학회, 145-189.

☑️ {논문제목}_{저자}_{연도}
→ ‘에서’ 주어의 통사와 의미_김민국_2017

☑️ {저자}_{연도}_{논문제목}
→ 김민국_2017_‘에서’ 주어의 통사와 의미

_________________________________________

💡 설정은 저장되어 계속 적용됩니다.
한 번 원하는 형식을 설정해 두면 이후에도 저장된 설정이 계속 적용됩니다.
또한 학술지 논문과 학위 논문의 설정은 서로 독립적으로 작동하므로,
각각 원하는 형식을 따로 지정할 수 있습니다.

📁 논문은 '논문' 폴더에 저장됩니다.
파일명은 설정한 형식에 따라 자동으로 만들어지며,
다운로드한 논문은 '논문' 폴더에 정리됩니다.

🌐 지원 사이트 (국내 6대 학술 DB)
대한민국 연구자라면 빠질 수 없는 주요 학술 사이트를 모두 지원합니다.

RISS 
KCI 
KISS
DBpia
교보문고 Scholar 
e-Article 

📌 참고
• 지원되는 학술 DB에서 제공하는 서지정보를 기반으로 파일명을 생성합니다.
• 논문의 서지정보가 학술 DB에서 제공되지 않는 경우 일부 정보가 표시되지 않을 수 있습니다.
• 파일명에 사용할 수 없는 문자는 자동으로 정리됩니다.
• 사용자 지정 양식에서는 제공되는 변수를 원하는 순서로 자유롭게 조합할 수 있습니다.
